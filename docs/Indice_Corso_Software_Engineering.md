# 📚 FridgeSavvy: Corso e Documentazione di Software Engineering

Benvenuto nell'Indice Generale del progetto FridgeSavvy. 
Questa cartella (`docs/`) e i suoi sottocapitoli contengono tutto il percorso logico, metodologico e ingegneristico che stiamo seguendo per creare il nostro prodotto reale e funzionante. L'ordine dei capitoli rispetta rigorosamente le best practices dell'industria, le fasi dell'**SDLC** (Software Development Life Cycle).

---

## 📖 Indice dei Capitoli (Ciclo di Vita del Software)

### Capitolo 00: Fondamenti Teorici
Concetti trasversali e accademici utili al System Design per la propria formazione personale o per futuri colloqui tecnici.
*   [Appunti di Software Engineering](./00_Fondamenti_Teorici/Lezioni_Software_Engineering.md)

### Capitolo 01: Idea e Requisiti (Requirements Gathering)
Cosa vogliamo costruire, perché lo facciamo e quali sono le prime fasi organizzative industriali.
*   [Il Ciclo di Vita del Software e i Prossimi Passi](./01_Idea_e_Requisiti/Lezione_2_SDLC_e_Prossimi_Passi.md)

### Capitolo 02: System Design e Architettura (High-Level Design)
Come dividere il nostro sistema in macro-blocchi separati (React Native, Node.js, Python, NoSQL, Storage) e come comunicano tra loro.
*   [Knowledge Base / Riepilogo delle Tecnologie Scelte](./02_System_Design_e_Architettura/Knowledge_Base_Riepilogo.md)
*   [Diagramma UML dell'Architettura di Sistema](./02_System_Design_e_Architettura/Architettura_Sistema.md)

### Capitolo 03: Detailed Design e Modellazione
La progettazione microscopica: come sono mappati i dati nel nostro Database, i flussi specifici di logica nel codice, il Design delle API (come chiamare i server in modo corretto) e il design dell'interfaccia utente.
*(Questo capitolo sarà riempito con le decisioni di Data Modeling Node.js)*
*   [01. Data Modeling in NoSQL (In Corso di Redazione) ](./03_Detailed_Design_e_Modellazione/Lezione_3_Data_Modeling_NoSQL.md)

### Capitolo 04: Sviluppo e Codice (Implementation & Coding)
*(In lavorazione...)* Conterrà snippet, configurazioni librerie e note operative pratiche su come scrivere il codice di React Native, come configurare Express in Node.js e come esporre l'intelligenza Artificiale in Python.

### Capitolo 05: Testing e Qualità (Testing Phase)
*(In lavorazione...)* Conterrà spiegazioni e script su come testare un server per garantire che non vi siano bug di sistema prima di mandarlo in produzione, attraverso Unit Testing o Integration Testing.

### Capitolo 06: Deploy e CI/CD (Rilascio sul Web)
*(In lavorazione...)* Conterrà l'enciclopedia dell'ultimo miglio. Spiegheremo come funzionano le macchine remote su cui eseguire il server online h24, e come configurare la **CI/CD** (Continuous Integration / Continuous Deployment), ovvero gli automatismi che inviano il tuo codice a Internet ogni volta che ne salvi una modifica sul computer.
